# Personal Project Notes

This folder is your personal tracker for everything we build in this RAG project.

## What is inside

- `PROJECT_OVERVIEW.md`: big-picture architecture and design choices.
- `SECURITY_NOTES.md`: security decisions, risks, and safe usage guidance.
- `updates/CHANGELOG.md`: dated timeline of everything new that was added.
- `updates/NEXT_UPDATES_RULE.md`: update policy for future work.

## Update commitment

After every new feature or meaningful change, this folder will be updated with:

1. What changed
2. Why it was added
3. Which files were affected
4. How to run or verify it
