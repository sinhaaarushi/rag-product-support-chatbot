# Update Rule (For Every New Change)

From now on, after each meaningful change, update this notes area.

## Mandatory update targets

1. Always append to:
   - `My_Project_Notes/updates/CHANGELOG.md`

2. Update if impacted:
   - `My_Project_Notes/PROJECT_OVERVIEW.md` (architecture/component behavior changes)
   - `My_Project_Notes/SECURITY_NOTES.md` (security/auth/data-handling changes)

## Changelog entry format

Use this format for each new update block:

- Date/time
- What was changed
- Why it was changed
- Files touched
- How to test/verify

## Scope guidance

- Include only meaningful technical changes.
- Skip tiny formatting-only edits unless they affect behavior or operations.
